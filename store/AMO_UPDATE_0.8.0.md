# Firefox (AMO) — обновление до 0.8.0

Файлы: `dist/gladko-firefox-0.8.0.zip` и архив исходников (на вопрос о генераторах кода — «Да»).

**Release notes:**
RU: Исправление текста, набранного не в той раскладке (ghbdtn → привет): по горячей клавише Alt+Shift+L, подсказкой или автоматически с отменой. Работает прямо в браузере, включается в настройках.
EN: Fix text typed in the wrong keyboard layout (руддщ → hello): with Alt+Shift+L, as a suggestion, or automatically with undo. Runs locally in the browser; enable it in settings.

**Notes to reviewer:**
- New feature: converting text typed in the wrong keyboard layout (Russian/English). Off by default.
- New file `layout-data.js` is data, not code: the 10,000 most frequent Russian and English words and
  letter-bigram log-probabilities. It is generated by `scripts/gen-layout-data.py` from the `wordfreq` 3.1.1
  package (CC BY-SA 4.0 data, attributed in THIRD_PARTY_LICENSES.md). It is loaded only by the background script.
- Detection runs locally; no text is sent anywhere for this feature. No new permissions.
- New command `fix-layout` (Alt+Shift+L).
- Everything else as before: no analytics, no remote code, no minification. Build steps: BUILD.md.
