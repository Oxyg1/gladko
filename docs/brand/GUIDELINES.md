# Гладко — правила использования логотипа

## 1. Логотип
- **Идея**: волнистая линия, которой подчёркивают ошибку, разглаживается в ровную черту — текст стал гладким.
- **Версии**: горизонтальная (основная) · вертикальная · только знак · только надпись.
- **Мастер-файлы** (`final/`):

| Файл | Когда использовать |
|---|---|
| `gladko-horizontal.svg` | основная версия на светлом фоне |
| `gladko-horizontal-on-dark.svg` | на тёмном фоне, в цвете |
| `gladko-stacked.svg` / `-on-dark.svg` | узкие и квадратные места |
| `gladko-symbol.svg` | знак от 48 px и крупнее |
| `gladko-symbol-small.svg` | знак 16–32 px (иконка, favicon) — толще линия, крупнее плитка |
| `gladko-wordmark.svg` | только надпись |
| `variants/*-black/-white/-mono-126067.svg` | в один цвет: печать, гравировка, штампы |
| `*-knockout.svg` | одноцветные мастера с настоящим вырезом волны |
| `png/icon-*.png`, `png/favicon.ico` | готовые растровые иконки |

## 2. Охранное поле
Вокруг логотипа оставляйте пустое поле не меньше **¼ высоты знака** (плитки) со всех сторон.
Поле масштабируется вместе с логотипом.

## 3. Минимальный размер
| Версия | Экран | Печать |
|---|---|---|
| Горизонтальная | 96 px в ширину | 25 мм |
| Знак | 16 px (файл `-small`) | 6 мм |

До 32 px включительно всегда используйте `gladko-symbol-small.svg`.

## 4. Цвет
| Название | HEX | RGB | CMYK (≈) | Pantone (≈, сверить по вееру) |
|---|---|---|---|---|
| Бирюза — основной | `#126067` | 18 96 103 | 83 7 0 60 | 7714 C |
| Чернила — текст | `#1C2A2D` | 28 42 45 | 38 7 0 82 | 7546 C |
| Абрикос — тёплый акцент | `#F2A45A` | 242 164 90 | 0 32 63 5 | 1485 C |
| Бумага — фон | `#F7F5F0` | 247 245 240 | 0 1 3 3 | — |

Белый текст на бирюзе — контраст ≈ 7.3 : 1 (WCAG AAA).
Абрикос — только как акцент (выделения, иллюстрации), не для логотипа.

**Разрешённые сочетания**: цветной логотип на белом / «Бумаге» · `-on-dark` на «Чернилах» или чёрном ·
белый одноцветный на бирюзе · чёрный одноцветный на белом.

## 5. Шрифт
- Надпись — **Manrope SemiBold/Bold (≈750)**, переведена в кривые; не набирайте её заново.
- Для интерфейса и текстов: Manrope или системный стек `system-ui, "Segoe UI", sans-serif`.
- Лицензия Manrope — SIL Open Font License 1.1 (свободно, в том числе для логотипов).

## 6. Нельзя
Растягивать и сжимать · перекрашивать вне палитры · поворачивать · добавлять тени, обводки, градиенты ·
менять местами или пропорции знака и надписи · ставить на пёстрый фон без подложки ·
использовать большую версию знака меньше 48 px.

## 7. Что осталось сделать
- Профессиональная проверка товарного знака и уникальности имени «Гладко» в каталоге addons.mozilla.org.
- Контуры волны сейчас собраны из коротких отрезков (≈100 узлов) — визуально гладко, но для печатных
  мастеров (PDF/EPS) стоит перерисовать кривыми Безье в векторном редакторе.
- Белую версию на тёмном фоне при крупной печати можно чуть утончить (эффект иррадиации).
